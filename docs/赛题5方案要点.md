# 赛题 5：AI+学科交叉方案要点

## 赛题理解

赛题 5 强调“人工智能 + 学科交叉”的深度融合。团队应选择一个具体学科或专业方向，围绕该学科的理论研究、教学实践、实验实训、个性化学习等核心环节，展示 AI 技术对学科建设的赋能价值。

本项目选择“AI + 医学”，重点不是做一个泛化聊天网站，而是做一个医学学科建设平台：把 Agent 工作流、RAG 证据检索、知识图谱和教学评价嵌入医学学习与科研训练。

## 产品定位

医智交叉引擎：面向医学教学、临床科研训练和病例推理实训的 AI 学科交叉网站。

## 可展示创新点

1. Agent 工作流：规划、检索、合规、教学设计、效果评价多 Agent 协作。
2. RAG 证据链：回答医学教学问题时返回引用，不让模型裸答。
3. 知识图谱：连接疾病、症状、检查、教学目标、AI 能力和合规边界。
4. 教学闭环：从问题诊断到学习路径、病例训练、效果评价形成闭环。
5. 合规设计：强调隐私、授权、非诊疗声明和人工复核。

## 效果验证建议

- 学生病例推理题正确率提升。
- 教师备课与病例材料整理时间下降。
- 文献证据检索覆盖率和引用准确率提升。
- 个性化学习路径完成率提升。
- 用户满意度和可推广性问卷评分。
