# 网站访问审计

入口：管理员 → 系统控制台 → 网站访问与操作审计，可直接访问 `/admin/dashboard#access-audit`。

- 面板每 5 秒自动刷新，支持暂停、手动刷新、分页、账号/姓名/IP/页面路径搜索及事件类型筛选。
- 浏览页面记录登录用户的账号、姓名、角色；没有有效登录状态时记录为未登录访客。身份从服务器会话验证，不接受浏览器指定账号。
- 登录成功/失败、后端修改类操作请求单独记录。原有操作详情审计继续保留并自动刷新。
- 每条记录包含时间、网络地址、站内页面/接口路径、事件、请求结果和浏览器信息。不保存密码、请求正文、令牌、完整查询参数。
- 数据保存在 `data/access_audit.sqlite3`，重启后仍保留。该文件已排除在 Git 提交之外；原有 `audit_logs.jsonl` 不受影响。
- 访问页面后开始记录，不会补造启用前的历史访问。浏览记录依赖页面 JavaScript 上报；禁用脚本、拦截上报的请求不会形成页面浏览记录。后端登录和修改操作独立记录。
- 在线会话根据可见页面每 30 秒发送的心跳、最近 90 秒活动估算。会话数不等于实际人数；共享网络、代理或 NAT 下的相同 IP 也不能确认是同一个人。

## 网络地址

服务使用服务器识别的客户端地址，不在业务代码中直接信任任意 `X-Forwarded-For`。本地 Vite 代理覆盖转发地址为真实连接来源，避免客户端自行伪造转发头。

部署到反向代理后，应只允许受信任代理访问后端，并在该边界覆盖客户端 IP（例如 Nginx 使用 `proxy_set_header X-Forwarded-For $remote_addr;`）。Uvicorn 的 `forwarded-allow-ips` 仅配置实际代理地址，不要无条件设为 `*`。多级代理/CDN 需要先配置并验证可信地址链，否则审计显示的可能是代理或网关地址。

## 验证

`backend/tests/test_access_audit.py` 使用临时数据库验证身份、访客、权限拒绝、分页、重启读取、心跳不增加浏览量、敏感参数去除和伪造 IP 头忽略。

浏览器验收使用未登录窗口访问落地页，管理员面板在自动刷新后显示访客记录；检查页面无脚本异常及小屏整页横向溢出。前端生产构建通过。
