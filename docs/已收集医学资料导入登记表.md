## 导入规则

1. 一个 PDF 对应一个 `document_id`，不按页创建顶层知识条目。
2. OCR 结果按页保存为内部片段，必须保留页码、章节路径和原图定位。
3. 自动跳过空白页、目录页、版权页、编委页和出版信息页的检索候选。
4. 生成 Embedding 时保存模型名、维度、文本哈希和生成时间。
5. 教材和解剖图谱进入“教材”；指南、共识和临床路径进入“医学依据”。
6. 导入前检查重复文件：文件哈希相同只保留一份，目录校对版只作为辅助来源。
7. 所有资料必须补齐来源、版本、发布日期、版权/授权说明和审核人。

## 管理员操作顺序

`选择资料类型` → `上传整本文档` → `OCR` → `章节/页码校正` → `脱敏检查` → `Embedding` → `图谱更新` → `教师审核` → `发布`
