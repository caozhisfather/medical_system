# 医学教学知识库资料收集清单

用于管理员统一收集、审核、脱敏、OCR、切分和导入。优先使用正式出版社、国家机构或学术组织公开版本，并记录版本、发布日期、版权状态和原始链接。

## 一、基础医学与形态学

- [ ] 组织学与胚胎学：人民卫生出版社本科规划教材最新版
- [ ] 组织学图谱：正常组织、细胞和显微结构对照图谱
- [ ] 胚胎发育时序、器官发生和先天畸形示意图
- [ ] 生理学：循环、呼吸、消化、泌尿、神经和内分泌系统
- [ ] 生物化学与分子生物学：代谢通路、遗传病和实验室指标
- [ ] 病理学：炎症、肿瘤、免疫、血管病变和常见器官病理图
- [ ] 病理生理学：休克、缺氧、酸碱平衡、电解质和器官功能衰竭
- [ ] 药理学：药物分类、作用机制、不良反应、禁忌证和相互作用

## 二、临床通用资料

- [ ] 诊断学：问诊、体格检查、实验室检查和影像学基础
- [ ] 临床检验指标参考范围及异常结果解释
- [ ] 医学影像学基础：X 线、CT、MRI、超声和核医学常见征象
- [ ] 临床技能操作规范：无菌技术、穿刺、急救和患者安全
- [ ] 医患沟通、知情同意、医学伦理和病历书写规范
- [ ] 《中国临床诊疗指南释义》或国家卫健委公开诊疗规范

## 三、内科与急诊

- [ ] 内科学本科教材及内科常见病诊疗规范
- [ ] 循环系统：高血压、冠心病、心力衰竭、心律失常和瓣膜病
- [ ] 呼吸系统：肺炎、哮喘、COPD、肺栓塞和呼吸衰竭
- [ ] 消化系统：胃肠疾病、肝病、胆道疾病、胰腺炎和消化道出血
- [ ] 泌尿系统：肾炎、肾衰竭、尿路感染和电解质紊乱
- [ ] 血液系统：贫血、白血病、淋巴瘤和凝血异常
- [ ] 内分泌系统：糖尿病、甲状腺、肾上腺和骨代谢疾病
- [ ] 神经系统：卒中、癫痫、头痛、感染和神经退行性疾病
- [ ] 急诊医学：胸痛、腹痛、意识障碍、创伤、休克和中毒

## 四、外科及其他专科

- [ ] 外科学：围手术期管理、感染、创伤、休克和常见手术适应证
- [ ] 妇产科学：妊娠管理、产科急症、妇科肿瘤和常见妇科病
- [ ] 儿科学：儿童生长发育、感染、先天性疾病和儿科急症
- [ ] 传染病学：传染病报告、隔离、防护和常见传染病诊疗
- [ ] 精神病学：精神状态检查、风险评估和常见精神障碍
- [ ] 皮肤性病学、眼科学、耳鼻咽喉科学、口腔医学常见病资料
- [ ] 康复医学、全科医学、老年医学和重症医学基础资料

## 五、优先收集的权威来源

- [ ] 国家卫生健康委员会、国家中医药管理局公开规范和技术指南
- [ ] 中国疾病预防控制中心公开指南、监测和防控资料
- [ ] 中华医学会及其专科分会发布的临床诊疗指南
- [ ] 中国医师协会、国家医学考试相关技能规范
- [ ] WHO、CDC、NICE、AHA、ESC、IDSA 等组织公开指南
- [ ] Cochrane、PubMed Central 等可合法访问的循证医学资料

## 六、管理员导入审核字段

每份资料至少登记：`标题`、`学科/专科`、`资料类型`、`作者/发布机构`、`版本`、`发布日期`、`来源链接`、`版权状态`、`适用人群`、`OCR 状态`、`embedding 状态`、`审核人`和`审核时间`。

目录页、版权页、空白页和重复 OCR 文本应在切分前清理；每个知识片段保留页码、章节路径和原始文件 ID，确保检索结果可追溯。
