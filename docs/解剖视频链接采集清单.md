# 解剖训练 B 站视频链接采集清单

## 分工与验收

- 负责人：待分配 1 名同学统一检索、初筛和录入。
- 审核人：课程组教师或具备相关专业背景的同学。
- 只录入具体视频页链接，不录入搜索结果页、合集首页或转载来源不清的链接。
- 视频需与对应器官和精细结构直接相关，内容清晰，无真实患者隐私，不包含面向真实患者的诊疗建议。
- 记录讲者/机构、时长、发布日期和版权备注；审核通过前保持 `待审核` 状态。

## 录入格式

审核后，将视频信息加入 `data/anatomy.json` 对应练习的 `video_resources`：

```json
{
  "title": "视频标题",
  "url": "https://www.bilibili.com/video/BV...",
  "platform": "bilibili",
  "status": "已审核",
  "contributor": "采集同学姓名",
  "reviewed_at": "2026-08-10"
}
```

前端离线兜底数据 `frontend/src/data/anatomy.ts` 需同步相同内容。
