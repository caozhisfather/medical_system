# 八大系统 B 站讲解视频与解剖图素材收集清单

> 用途：为医学教学系统的“解剖练习”模块收集可分层浏览的解剖图和配套 B 站讲解视频。  
> 原则：视频优先选择医学院校、医院、医学教师或专业医学教育 UP 主；图片必须记录来源和授权信息。

## 一、收集目标

- B 站视频：每个系统优先收集 4～6 个，共约 40 个。
- 解剖图片：每个系统优先收集 5～10 张，共约 60 张。
- 第一轮最低目标：8 张系统总览图，以及每个系统 3 张核心器官精细图。
- 同一视频主题建议收集 1 个主链接和 1 个备用链接。
- 图片优先选择 SVG 或高清 PNG，方便添加可点击热点。

## 六、素材筛选标准

### 视频要求

- [ ] 发布者为医学院校、医院、医学教师或专业医学教育 UP 主。
- [ ] 解剖名称和结构关系准确，无明显医学错误。
- [ ] 画面清晰，结构标注能够辨认。
- [ ] 最好为 5～30 分钟，或记录了重点讲解时间段。
- [ ] 内容适合医学教学，不用患者真实隐私资料作为展示素材。
- [ ] 链接可以正常打开。

### 图片要求

- [ ] 优先选择 SVG、高清 PNG，避免压缩严重的截图。
- [ ] 结构轮廓清楚，适合覆盖可点击热点。
- [ ] 最好为无文字版，或中英文标注清晰的版本。
- [ ] 有正面、背面、剖面或观察方向说明。
- [ ] 记录原始网页、作者和授权协议，不只记录图片直链。
- [ ] 优先使用 Wikimedia Commons、OpenStax、Servier Medical Art 等授权明确的来源。
- [ ] 不使用教材扫描图、付费图库图或版权信息不明确的搜索引擎图片。
