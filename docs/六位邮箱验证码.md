# 六位邮箱验证码

注册后进入 `/verify-email`，填写注册邮箱和六位验证码。验证成功后使用原账号密码登录；教师账号仍需管理员审核。

- 验证码含前导零，10分钟有效，每次只能使用一次。
- 同一账号60秒内不能重复发送，一小时最多5次（含注册时发送）。
- 重新发送使旧验证码失效。连续输错5次后必须重新获取。
- 邮件发送失败后可以立即重试，仍受每小时次数限制。
- 验证码使用独立随机盐和 PBKDF2 哈希保存，不在接口响应中返回。
- 找回密码继续使用原有一次性链接。旧的注册验证链接请改用“重新获取验证码”。

## 接口

- `POST /api/auth/register`：创建待验证账号并发送验证码。
- `POST /api/auth/resend-verification`：`{ "email": "用户邮箱" }`。
- `POST /api/auth/verify-email`：`{ "email": "用户邮箱", "code": "六位数字字符串" }`。

## 配置和升级

邮件配置由后端读取 `env/.env`，发件人显示名称为 `MAIL_FROM_NAME`。授权码仅保存到私有配置，不得上传仓库。

后端启动自动创建 `email_verification_codes` 表及用户时间索引，外键关联 users。无需重置数据库，现有用户、密码、会话和密码重置记录保留。升级时前后端需同时更新。

本地代码更新不会自动部署到远程服务器。服务器需同步代码、私有邮箱配置，并重启后端。
