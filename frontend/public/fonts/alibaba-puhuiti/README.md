# Alibaba PuHuiTi

Font files in this directory are extracted from the official Alibaba PuHuiTi
font package supplied with the project.

Included weights:

- Alibaba-PuHuiTi-Regular.otf
- Alibaba-PuHuiTi-Medium.otf
- Alibaba-PuHuiTi-Bold.otf
- Alibaba-PuHuiTi-Heavy.otf

The font is loaded locally by `frontend/src/styles.css`. No font files are
requested from a third-party CDN at runtime.
