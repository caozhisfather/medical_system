# MiSans

Font files in this directory are extracted from the official MiSans font
package (MiSans.zip) supplied with the project. Only the woff2 weights used by
the interface are included.

Included weights:

- MiSans-Regular.woff2 (400)
- MiSans-Medium.woff2 (500)
- MiSans-Semibold.woff2 (600)
- MiSans-Bold.woff2 (700)
- MiSans-Heavy.woff2 (800 / 900)

The font is loaded locally by `frontend/src/styles.css`. No font files are
requested from a third-party CDN at runtime.
