# 佐证材料清单

佐证材料最终需要合并为一个 PDF。

## 一、知识产权类

- [ ] 软件著作权登记证书或受理通知 `[待申请]`
- [ ] 专利受理通知书 `[如无则删除]`
- [ ] 论文录用通知或论文首页 `[如无则删除]`
- [ ] 开源组件许可证清单

## 二、应用成效类

- [ ] 试点班级和时间说明

- [ ] 教师使用反馈

## 三、技术验证类

- [ ] 自动化测试报告

- [ ] 教材检索命中样例
- [ ] 定位测验评分样例
- [ ] 并发和失败回退测试

- [ ] 隐私保护设计说明
- [ ] 医学教育用途声明

## 五、代码和复现类

- [ ] 完整代码包
- [ ] 依赖清单

## 六、合并顺序

1. 佐证材料目录
2. 知识产权材料
