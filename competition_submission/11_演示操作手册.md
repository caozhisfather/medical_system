# 演示操作手册

## 一、启动前检查

```powershell
conda activate pytorch_env
python -m backend.app.main
```

另开终端：

```powershell
pnpm --dir frontend dev
```

检查地址：

- 前端：`http://127.0.0.1:5173`
- 后端：`http://127.0.0.1:8000/api/health`
- API 文档：`http://127.0.0.1:8000/docs`

## 三、演示前数据准备

- [ ] 重置或清理测试记录
- [ ] 使用演示班级和虚拟学生
- [ ] 检查教材页可以打开
- [ ] 检查教材检索至少有一个可靠结果
- [ ] 检查三维模型可以加载
- [ ] 检查网络和知识图谱 API
- [ ] 检查浏览器缩放为 100%
- [ ] 关闭无关通知和聊天软件
- [ ] 清空浏览器书签栏

## 四、学生演示顺序

1. 登录学生账号。
2. 打开学习总览。
3. 进入三维人体解剖。
4. 选择循环系统、心脏和精细结构。
5. 演示隐藏器官和精细结构。
6. 打开教材详解。
7. 放大教材页。
8. 使用画笔和荧光笔勾画。
9. 在旁边写笔记。
10. 关闭并重新打开教材，确认标注保存。
11. 切换到空间定位测验。
12. 点击二维器官图，提交并展示评分。
13. 打开学习档案，查看测验记录和错题。
14. 打开知识图谱。

## 五、教师演示顺序

1. 登录教师账号。
2. 查看教学总览。
3. 打开教学知识库。
4. 展示教材和医学依据筛选。
5. 打开题型与提示词。
6. 修改题型或权重。
7. 展示系统提示词。
8. 打开知识图谱。

## 六、管理员演示顺序

1. 登录管理员账号。
2. 查看系统状态。
3. 打开 Skill 管理。
4. 演示 Skill 启停、角色权限和额度。
5. 查看调用记录。
6. 查看数据源状态。
7. 查看知识库和图谱状态。

## 七、失败回退

如果外部 AI 服务不可用：

- 教材证据仍要显示。
- 定位测验仍要可提交。
- 已保存笔记仍要可查看。
- 图谱和三维模型仍要可使用。

如果三维模型首次加载慢：

- 不反复刷新。
- 先演示二维定位和教材功能。
- 模型加载完成后返回三维。
