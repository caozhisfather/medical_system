# 匿名与版权合规检查表

## 一、匿名检查

以下材料都需要检查：

- 技术方案
- 演示视频
- 答辩 PPT
- 佐证材料
- 页面截图
- 浏览器书签栏
- 系统文件路径
- GitHub 页面
- 终端窗口
- 数据库路径
- 邮件签名

检查项：

- [ ] 不出现学校名称
- [ ] 不出现学校简称
- [ ] 不出现学校 Logo
- [ ] 不出现校徽颜色组合
- [ ] 不出现指导教师姓名
- [ ] 不出现班级真实名单
- [ ] 不出现个人邮箱和手机号
- [ ] 不出现真实患者身份信息
- [ ] 不出现带学校信息的本地路径

## 二、医学边界

- [ ] 明确系统只用于医学教育
- [ ] 明确不提供诊断、治疗和处方建议
- [ ] 明确模型补充内容与教材原文分开
- [ ] 真实病例必须脱敏
- [ ] 演示优先使用合成的虚拟病例
- [ ] 页面和视频保留安全声明
