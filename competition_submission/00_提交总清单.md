# 提交总清单

## 一、报名信息

- [ ] 确认团队成员不超过 3 人
- [ ] 确认队长和指导教师信息
- [ ] 确认团队成员均为本校正式学籍学生
- [ ] 确认没有跨校组队
- [ ] 确认报名截止前完成系统提交
- [ ] 保存报名编号、赛题名称和系统截图

## 二、必交材料

- [ ] 作品名称，20 字以内
- [ ] 作品简介，300 字以内
- [ ] 技术方案 PDF，10 MB 以内，正文 8000 字以内
- [ ] 演示视频 MP4，3-5 分钟，300 MB 以内
- [ ] 答辩 PPT 或答辩 PDF
- [ ] 佐证材料 PDF
- [ ] 百度网盘永久分享链接
- [ ] 提取码
- [ ] 网盘材料命名符合官方格式

## 三、技术方案检查

- [ ] 项目背景与意义
- [ ] 参赛方向定位
- [ ] 需求分析
- [ ] 系统架构和数据流
- [ ] AI 技术选择和实现方法
- [ ] 核心创新点
- [ ] 实验设计和测试数据
- [ ] 系统实施与应用情况
- [ ] 局限和改进方向
- [ ] 附录、核心代码和参考文献
- [ ] 全文无学校、Logo、指导教师信息

## 四、演示视频检查

- [ ] 视频总时长在 3-5 分钟之间
- [ ] 使用 MP4 格式
- [ ] 文件小于 300 MB
- [ ] 画面不含学校名称和 Logo
- [ ] 演示账号未显示真实个人信息
- [ ] 录屏清晰可读
- [ ] 教材页、标注、笔记、图谱和定位得分完整出现
- [ ] 全程说明系统仅用于医学教育

## 五、答辩 PPT 检查

- [ ] 背景和痛点
- [ ] 目标用户和真实需求
- [ ] 系统架构
- [ ] AI 技术方案
- [ ] 核心创新
- [ ] 功能演示截图
- [ ] 测试和试点数据
- [ ] 应用价值和推广方案
- [ ] 风险和局限
- [ ] 未来规划
- [ ] 导出为 PDF
