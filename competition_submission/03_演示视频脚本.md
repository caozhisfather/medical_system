# 演示视频脚本

目标时长：4 分 20 秒。

## 00:00-00:25 问题与定位

画面：

- 首页或学习总览。
- 教材页、三维结构和二维定位图快速切换。

旁白：

“解剖学习需要同时处理结构名称、三维位置、教材原文和练习记录。临思智训把这些内容连接到一个可追溯的学习流程中，系统只用于医学教育，不用于临床诊断。”

## 00:25-00:50 技术架构

画面：

- 技术方案中的架构图。
- Vue、Three.js、FastAPI、教材证据、知识图谱和 SQLite 标签。

旁白：

“前端使用 Vue 3、TypeScript 和 Three.js，后端使用 FastAPI。系统包含三维模型、教材证据、知识图谱、定位测验、学习档案和 Skill 权限治理六条主线。”

## 00:50-01:45 学生完整学习流程

画面：

1. 学生登录。
2. 进入三维人体解剖。
3. 选择循环系统和心脏。
4. 展示器官和精细结构隐藏。
5. 点击心脏结构。

旁白：

“学生可以按整体人体、系统、器官和精细结构逐层探索。系统目前包含 1742 个三维结构和 9 个教学系统。”

## 01:45-02:35 教材、勾画和笔记

画面：

1. 打开教材详解。
2. 展示教材优先讲解。
3. 展开 Markdown 标题和表格。
4. 点击教材页放大。
5. 使用画笔和荧光笔。
6. 在旁边写笔记。
7. 关闭后重新打开，确认标注恢复。

旁白：

“教材讲解优先引用上传资料，并显示书名、页码、行号和原文页图。模型补充内容单独标注。学生可以放大教材、勾画和记录笔记，内容按账号保存。”

## 02:35-03:20 二维定位和评分

画面：

1. 切换到空间定位测验。
2. 显示二维心腔精细图。
3. 点击目标结构。
4. 提交定位。
5. 展示得分、标准区域和解析。
6. 打开学习档案。
7. 展示测验记录和错题本。

旁白：

“定位测验使用器官或精细结构二维图。点击位置会记录坐标，提交后服务端完成评分。错误题自动进入错题本，学习档案保存每次作答。”

## 03:20-03:55 教师和管理员

画面：

1. 教师知识库。
2. 题型、权重和提示词。
3. 管理员 Skill 管理。
4. Skill 调用记录。

旁白：

“教师维护教材和医学依据，配置题型和系统提示词。管理员决定 Skill 启停、角色权限和小时额度，所有调用都有记录。”

## 03:55-04:20 创新点和总结

画面：

- 四张核心截图：三维结构、教材页、定位评分、知识图谱。

旁白：

“项目的核心是把三维探索、教材证据、二维定位、标注笔记和错题复习连接起来。教材原文和模型补充严格分开，AI 能力由管理员控制。当前版本已经通过主要流程验证，下一步将开展真实学生试点并完成医学审校。”
