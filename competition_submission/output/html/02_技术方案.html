临思智训：教材可追溯的解剖学习平台

一、项目概述

1.1 项目背景与意义

解剖学是医学教育的基础课程。学生需要同时掌握结构名称、空间位置、周边关系和临床联系。当前学习过程通常依赖教材、图谱、三维模型和题库等多个工具，教材中的文字描述与三维结构之间缺少直接连接，定位练习和错题记录也容易被分散在纸张、截图或聊天工具中。

临思智训面向医学教育场景，构建三维解剖探索、二维结构定位、教材证据、逐页笔记、知识图谱和学习档案之间的连接。系统不提供诊断、治疗或处方建议，只用于教学、竞赛演示和技术研究。

1.2 赛题方向定位

项目属于 AI+医学方向，聚焦医学教育中的自主学习与实验实训。核心技术包括三维可视化、教材证据检索、OpenAI 兼容模型、知识图谱、服务端评分和 Skill 权限治理。

二、需求分析

2.1 学生需求

学生需要在同一个学习环境中完成以下任务：

  1. 观察人体系统和器官的三维位置。
  2. 查看中文、英文结构名称。
  3. 从结构进入教材页，并知道具体页码和行号。
  4. 在教材页上放大、勾画和记录笔记。
  5. 使用二维器官或精细结构图进行定位练习。
  6. 提交答案后立即得到评分和解析。
  7. 从学习档案查看历史测验和错题。
  8. 通过知识图谱理解结构、疾病、检查和病例之间的联系。

2.2 教师需求

教师需要：

  1. 导入教材、指南和病例资料。
  2. 查看 OCR、向量化和图谱处理状态。
  3. 配置测验题型、难度和权重。
  4. 编辑出题系统提示词。
  5. 查看班级共性薄弱结构和教学建议。

2.3 管理员需求

管理员需要：

  1. 审核教师账号。
  2. 管理数据源和知识库状态。
  3. 控制 Skill 启停、角色权限和小时额度。
  4. 查看 Skill 调用记录和系统运行状态。
  5. 确认 Agent 只在批准范围内调用只读工具。

四、关键 AI 技术与实现

4.1 教材证据检索

系统优先读取管理员上传文档的逐页 OCR 结果。检索分为两个层次：

  1. 有向量索引时，使用 Embedding 计算语义相似度。
  2. 向量索引不可用时，使用 OCR 文本词法检索回退。

结果返回文档标题、页码、行号、匹配文本、相似度和原始页图。当前演示数据中向量索引数量为 0，实际主要使用 OCR 词法回退。

4.2 教材证据约束讲解

模型回答使用 教材依据 和 模型补充说明（非教材原文） 两段结构。Prompt 规定：

  • 只能根据给定教材证据回答。
  • 教材没有或一笔带过时才允许补充。
  • 每个关键结论后标注资料编号、页码和行号。
  • 不得编造页码。
  • 不提供诊断或治疗建议。
  • 涉及结构、位置或临床联系对比时，优先使用 Markdown 表格。

前端使用 Marked 解析 Markdown，使用 DOMPurify 过滤 HTML，支持标题、列表、引用、代码和 GFM 表格。

4.3 三维解剖

三维模型包含 1742 个结构、11 个几何分块、约 141 万个三角形和 9 个教学系统。系统按系统按需加载几何块，使用合并网格和材质组控制结构显示，支持旋转、缩放、系统聚焦、器官隐藏、精细结构隐藏和结构高亮。

4.4 二维空间定位

定位题使用器官或精细结构二维图。前端根据题目和精细结构解析图谱节点与目标热点，点击后记录归一化坐标。坐标落在目标区域时判为正确，提交后显示标准和评分。

4.5 教材页勾画与笔记

教材页使用 SVG 作为标注层，坐标统一映射到 0-1000 的归一化空间。用户可以使用画笔、荧光笔和单笔擦除。标注点、颜色、宽度、工具类型和笔记内容按账号、文档和页码保存。

4.6 知识图谱

解剖图谱分为四个层级：

  1. 人体解剖根节点
  2. 教学系统
  3. 器官
  4. 精细结构

当前解剖图谱包含 736 个节点和 1011 条关系，用于结构检索、关系浏览和学习路径展示。

4.7 Skill 权限治理

系统预置三个只读 Skill：

  • anatomy_search
  • textbook_search
  • graph_query

Skill 默认关闭。管理员决定启停、允许角色和每账号每小时额度。执行中、成功、无匹配和失败都会记录调用状态；禁用、无权限和额度拒绝不会占用额度。

五、创新点

5.1 教材证据优先，模型补充独立

系统把教材原文和模型补充严格分开，降低模型在没有教材依据时自行补写医学结论的风险。

5.2 三维学习与教材页双向连接

学生从三维结构进入教材证据，也可以从教材页查看原始页图、行高亮和笔记，减少在教材、模型和题库之间来回切换。

5.3 二维定位训练和学习档案闭环

系统使用二维器官图进行定位，记录每次点击坐标和得分，并把错误题目自动聚合到错题本，形成探索、练习、评分和复习闭环。

5.4 管理员控制的 Skill

系统不支持任意脚本和远程插件执行。AI 能力按照只读 Skill 处理，管理员可以撤权、限流和审计，适合医学教育中的边界控制。

5.5 标注和笔记可恢复

教材页标注使用归一化坐标保存，不依赖固定屏幕尺寸；学生重新打开教材后可以继续查看和编辑。

七、应用价值

7.1 学生价值

  • 把三维结构、教材证据和定位练习放在同一个学习过程中。
  • 记录每次测验和错题，减少重复查找。
  • 允许直接在教材页勾画和做笔记。

7.2 教师价值

  • 维护教材和医学依据。
  • 配置题型和提示词。
  • 查看学生共同薄弱结构。
  • 用可追溯证据替代不可验证的模型结论。

7.3 管理价值

  • 使用角色权限和 Skill 策略控制 AI 工具范围。
  • 对数据源、文档处理、图谱和调用行为进行审计。

八、局限与后续方向

8.1 当前局限

  • 向量索引当前为空，教材检索主要依赖 OCR 词法回退。
  • 学生笔记当前使用本地 JSON 保存，并发写入仍需要加强。
  • 学习效果尚未经过正式对照实验。
  • 三维图谱不是经过医学审校的血管或神经支配模型。
  • 系统不适合临床诊断和治疗决策。
  • 部分数字人、RAG 和早期临床训练模块仍是兼容或实验功能。

8.2 后续方向

  1. 完成教材向量索引建设。
  2. 将笔记迁移到支持并发写入的数据库。
  3. 完成学生试点和教师访谈。
  4. 对图谱热点和教材页码进行人工医学审校。
  5. 增加端到端测试、性能测试和弱网回退测试。
  6. 建设正式的版权、数据治理和内容审核流程。
