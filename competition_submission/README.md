# AIC AI+医学竞赛提交包

本目录按照第八届全球校园人工智能算法精英大赛 AI+医学赛题的作品提交要求整理。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `00_提交总清单.md` | 报名、材料、匿名、版权、部署和提交前检查 |
| `01_作品名称与简介.md` | 20 字以内作品名称、300 字以内简介和备用名称 |
| `02_技术方案.md` | 比赛技术方案正文，可按官方模板转为 PDF |
| `03_演示视频脚本.md` | 3-5 分钟演示视频分镜、字幕和录屏顺序 |
| `04_答辩PPT大纲.md` | 逐页答辩内容和讲稿提示 |
| `05_需求调研方案.md` | 学生问卷、教师访谈、试点方案和统计口径 |
| `06_应用成效记录表.csv` | 试点前后数据记录模板，禁止使用虚构数据 |
| `07_佐证材料清单.md` | 软著、专利、论文、试点和用户反馈等证明材料 |
| `08_匿名与版权合规检查表.md` | 学校和教师匿名、资源许可和教育边界检查 |
| `09_网盘材料与命名规范.md` | 代码包、工程文件、高清图和外链命名规范 |
| `10_答辩问答准备.md` | 评委常见问题、回答要点和风险边界 |
| `11_演示操作手册.md` | 比赛现场从启动到完整演示的操作步骤 |
| `12_部署细则.md` | 服务器目录、资料上传、OCR、向量索引和路径修复 |

## 已生成 PDF

以下 PDF 位于 `output/pdf/`，可直接用于内部评审和后续修改：

- `01_作品名称与简介.pdf`
- `02_技术方案.pdf`
- `04_答辩PPT大纲.pdf`
- `12_部署细则.pdf`

Markdown 是主编辑稿。修改 Markdown 后，可以重新生成 PDF。答辩材料还需要根据最后确定的真实试点数据补充第 4、13 页。

## 不得虚构的内容

以下内容必须使用真实调研或真实试点结果，不能由开发人员代填：

- 学生和教师访谈人数
- 问卷回收数量
- 使用前后正确率
- 教材查找时间变化
- 用户满意度和继续使用意愿
- 合作单位、试点班级和试点时间
- 软著、专利、论文和合作意向书状态

尚未完成的项在文档中标记为 `[待填写]` 或 `[待验证]`。

## 官方关键约束

- 校赛完成时间：2026 年 10 月 10 日前
- 省赛/区域赛报名截止时间：2026 年 10 月 15 日 20:00
- 团队人数：最多 3 人，队长 1 名，指导教师最多 2 名
- 作品名称：不超过 20 字
- 作品简介：不超过 300 字
- 技术方案：PDF，不超过 10 MB，正文不超过 8000 字
- 演示视频：MP4，3-5 分钟，不超过 300 MB
- 答辩 PPT：最终转为 PDF
- 佐证材料：合并为一个 PDF
- 所有材料不得出现学校名称、Logo 和指导教师信息
