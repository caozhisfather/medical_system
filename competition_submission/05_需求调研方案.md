# 需求调研方案

## 一、调研目标

验证医学院学生在解剖学习中是否存在以下问题：

1. 教材定位慢，难以从目录或 PDF 快速找到对应页和行。
2. 三维结构名称与教材描述之间缺少直接关联。
3. 二维器官和精细结构定位训练不足。
4. 笔记、勾画和测验记录分散，复习时需要重复查找。
5. 教师难以看到学生的共性薄弱结构。

## 二、学生问卷

建议样本：至少 30 份有效问卷。

1. 你目前就读年级和专业是什么？
2. 每周学习解剖学的平均时间是多少？
3. 你查找教材对应章节通常需要多久？
4. 学习三维结构时最容易遇到什么困难？
5. 你是否使用过二维器官图或精细结构图做定位练习？
6. 你是否在教材上做勾画和笔记？
7. 你的教材笔记和错题通常保存在哪里？
8. 复习时能否快速找到曾经做过的标注？
9. 你对“教材页定位 + 行高亮”的需求程度是多少？
10. 你对“三维结构 + 教材证据 + 知识图谱”联动学习的需求程度是多少？
11. 你对“二维定位测验自动评分”的需求程度是多少？
12. 你希望在测验后看到哪些反馈？
13. 你是否愿意使用统一学习档案记录解剖训练？
14. 你更希望使用电脑、平板还是手机学习？
15. 你认为当前解剖学习工具最需要改进的一点是什么？

## 三、教师访谈

建议访谈：至少 3 名解剖学或基础医学教师。

1. 学生最常见的解剖学习问题是什么？
2. 教材、图谱和题库之间是否存在割裂？
3. 教师如何判断学生是否真正掌握空间定位？
4. 哪些结构最容易混淆？
5. 教师是否愿意维护教材证据和知识图谱？
6. 教师需要看到哪些班级统计？
7. 怎样的测验反馈最适合教学？
8. 哪些内容不允许 AI 自由补充？
9. 教材和外部图谱资源有哪些版权限制？
10. 如果要试点，最合适的班级、课时和实施方式是什么？

## 四、试点设计

### 试点对象

- 建议人数：10-30 人
- 建议专业：临床医学、护理学、基础医学或相关专业
- 建议分组：对照学习和平台学习，或者使用前后自身对照

### 试点任务

1. 完成一次教材页定位。
2. 完成一次三维结构查找。
3. 完成一组二维定位测验。
4. 在教材页上完成勾画和笔记。
5. 查看测验记录和错题本。

### 评价指标

| 指标 | 统计方法 |
| --- | --- |
| 教材查找时间 | 从开始查找到找到目标页的秒数 |
| 结构定位正确率 | 正确题数 / 总题数 |
| 复习完成率 | 完成复习任务人数 / 总人数 |
| 笔记恢复效率 | 重新找到上次笔记所需时间 |
| 系统易用性 | 1-5 分问卷 |
| 学习意愿 | 1-5 分问卷 |
| 教师时间投入 | 单次教学准备和统计耗时 |

## 五、数据记录要求

- 保留原始匿名问卷。
- 保留教师访谈时间和匿名纪要。
- 记录试点日期、人数、任务和测试版本。
- 不记录真实患者信息。
- 不把演示数据的猜测量写成真实结果。
