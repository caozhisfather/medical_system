# 网盘材料与命名规范

## 一、根目录命名

```text
参赛团队编号-赛题名称-作品名称/
```

示例：

```text
AIC2026-XXXX-AI医学-临思智训/
```

## 二、材料命名

```text
参赛团队编号-赛题名称-作品名称-材料名称
```

示例：

```text
AIC2026-XXXX-AI医学-临思智训-完整代码包.zip
AIC2026-XXXX-AI医学-临思智训-技术方案.pdf
AIC2026-XXXX-AI医学-临思智训-演示视频.mp4
AIC2026-XXXX-AI医学-临思智训-答辩PPT.pdf
AIC2026-XXXX-AI医学-临思智训-佐证材料.pdf
AIC2026-XXXX-AI医学-临思智训-数据库说明.pdf
AIC2026-XXXX-AI医学-临思智训-高清界面图.zip
```

## 三、代码包建议结构

```text
00_README/
01_源码/
02_数据库初始化/
03_示例数据/
04_启动脚本/
05_测试报告/
06_界面截图/
07_资源许可与引用/
```

## 四、代码包不得包含

- `env/.env`
- 邮箱授权码
- API Key
- `data/auth.sqlite3`
- `data/skills.sqlite3`
- `data/student_notes.json`
- `data/anatomy_learning.sqlite3`
- 真实患者资料
- 运行日志
- 浏览器用户目录
- `node_modules`
- `frontend/dist`

## 五、链接检查

- [ ] 百度网盘分享永久有效
- [ ] 自动生成提取码
- [ ] 非团队账号可以访问
- [ ] 手机和电脑都能打开
- [ ] 文件夹内没有重复版本
- [ ] 文件夹内没有旧版视频
- [ ] 文件夹内没有测试数据
